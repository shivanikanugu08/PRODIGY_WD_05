# PRODIGY_WD_05
# 🌦️ Weather App — Prodigy InfoTech Internship Task 5

## 📋 Project Overview

This project is part of my **Web Development Internship at Prodigy InfoTech**.
The goal of this task was to **build a responsive web application** that fetches real-time weather data from an API and displays current weather information based on either the **user’s location** or a **manually entered city name**.

## 🚀 Features

* 🌍 Fetches weather using **OpenWeatherMap API**
* 📍 Detects **user’s current location** using Geolocation API
* 🔍 Allows manual **city search**
* 🌡️ Displays temperature, weather condition, humidity, and wind speed
* 🎨 Clean and modern **gradient UI** design
* 📱 Fully responsive and easy to use

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript (ES6)**
* **OpenWeatherMap API**

## 📚 Learning Outcomes

* Gained hands-on experience with **RESTful APIs**
* Implemented **Geolocation API** in web applications
* Enhanced **frontend design and JavaScript** skills
* Improved debugging and UI responsiveness
